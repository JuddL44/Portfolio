About Me

Software Development

I build full-stack web applications with .NET and Angular. My latest project is a deployed ecommerce platform on Azure with JWT auth, real-time cart management, and a CI/CD pipeline.

I care about code that's easy to change when requirements shift and interfaces that respect the user's time. Every project I ship has a live demo, a real README, and deployment you can actually visit.

History

Before web development, I shipped a multiplayer game on Steam built with C# and Unity, and created Minecraft maps for Mojang.

I've been writing C# for over a decade. I just point it at different problems now.

Beyond Code
